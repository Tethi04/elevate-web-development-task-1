## ✨ Key Features

* **Glassmorphism Design System:** Clean dark theme (`#0a0814`) with ambient glowing gradients and translucent cards using `backdrop-filter`.
* **Fully Responsive Layout:** Designed mobile-first using **CSS Flexbox** and dynamic **CSS Grid** (`repeat(auto-fit, minmax(...))`)[span_1](start_span)[span_1](end_span).
* **Interactive JavaScript Modal:** Clicking on featured showcase cards triggers a dynamic preview modal popup.
* **Mobile Navigation Toggle:** Smooth slide-out mobile menu for smaller screen sizes[span_2](start_span)[span_2](end_span).
* **Smooth Scrolling & Scrollspy:** Anchor links smoothly navigate to sections with active header navigation state highlights.

---

## 🛠️ Tech Stack & Tools

* **HTML5:** Semantic structural markup (`<header>`, `<main>`, `<section>`, `<footer>`)[span_3](start_span)[span_3](end_span).
* **CSS3:** Custom CSS variables, Flexbox, Grid, Media Queries, keyframe/hover animations, and Glassmorphism styling[span_4](start_span)[span_4](end_span).
* **JavaScript (ES6+):** Dynamic DOM creation, event delegation, smooth scrolling, and scrollspy scroll detection.
* **Development Tools:** Visual Studio Code & Live Server Extension[span_5](start_span)[span_5](end_span).
